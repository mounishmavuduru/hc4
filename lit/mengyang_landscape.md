Headline identities asserted by the scripts (verbatim):

```
det Jac F              = -2    (Alpöge/Fable map, constant Jacobian)
det Hess φ   (HC₆)     = -4    = (-1)³ · (det Jac F)²
det Hess Ψ̃   (HC₅)     = 128   Ψ̃ = A² + 13A + 2B, deg 14, 42 monomials
∇Ψ̃(±1, ∓3/2, 0, 0, 0) = (0, 0, -1/2, 0, 0)   (distinct points → ∇Ψ̃ non-injective)
```

README's provenance claim (verbatim): det Hess Ψ = 128 is "established **five**
independent ways": (i) exact bordered/rank-one Schur certificate; (ii) direct 5x5
`domain-ge` determinant; (iii) random-integer + multi-prime modular evaluation;
(iv) from-scratch no-CAS Bareiss determinant; (v) "Independently authored model
implementation (MiniMax-M3)". "Methods (i)-(iii) share SymPy; (iv) and (v) do not."

**Caveat for our purposes:** all five "independent" methods live in the authors' own
repo; the only "independently authored" script (`minimax_check.py`) is explicitly
"generated by MiniMax-M3", an AI model — there is **no third-party human verification
artifact in the repo**. Requirements: Python 3.8+, SymPy 1.12; scripts are fail-closed
(assert-based, nonzero exit on mismatch).

The README also states the descent-obstruction claim relevant to Track C (verbatim):
"The Schur descent requires a pivot variable in which the potential is affine-linear
with a degenerate reduced Hessian — a degeneracy the doubled potential owes to its
linearity in the dual variables y. A single descent already spends that linearity
(the descended potential becomes quadratic in those variables), so no further pivot
of the required type remains. Reaching HC₄ appears to require genuinely new ideas."

## 4. Independent verification / discussion landscape

### 4a. Secret Blogging Seminar thread (David Speyer, 2026-07-20) — richest source
URL: https://sbseminar.wordpress.com/2026/07/20/the-new-counterexample-to-the-jacobian-conjecture/

Meng & Yang announced their result in comment #41 (2026-07-27). Verbatim (as captured):

> "Dear friends and colleagues, We would like to share a new paper
> (https://arxiv.org/abs/2607.22198) ... we construct an explicit integer polynomial
> in five variables (total degree 14, constant Hessian determinant 128, non-injective
> gradient) that refutes the Hessian conjecture HC_5. ... exactly two statements
> remain undecided: – JC_2 ... and – HC_4 ... linked by a single bridge: HC_4 ==> JC_2.
> ... The HC_5 counterexample is self-contained and checkable by hand (it rests only
> on Alpoge's map having a constant Jacobian and a two-point collision), and all
> identities are independently verified in exact rational arithmetic. ...
> Question: Is there a natural way to view this two-parameter family of counterexample
> polynomials in 5 variables?"

**No replies to this comment confirm, question, or dispute the HC_5 counterexample**
(as of 2026-08-08). The thread's verification activity concerns Alpoge's JC_3 map:
Will Sawin (geometric construction via ChatGPT), wmayner ("machine-checked exactly",
scripts on GitHub), Skooi ("exact symbolic calculation"), and William Thompson
(24-variable cubic-homogeneous Bass-Connell-Wright reduction, "Two separately
implemented exact verifiers agree, including the nilpotence certificate (JN)^17 = 0";
Thompson self-identifies as "a 19-year-old Harvard undergraduate", work done "with
substantial assistance from GPT-5.6 Sol").

### 4d. Zenodo: Santibañez-Leal dimension-48 Hessian witness (parallel, NOT a verification of Meng-Yang)
URL: https://zenodo.org/records/21504303

Felipe Santibañez-Leal, "The consequence cascade of the Jacobian counterexample, with
an explicit dimension-48 witness against the Hessian conjecture", v0.03, 2026-07-23
(one day BEFORE Meng-Yang v1). Homogeneous quartic potential in 48 variables via
de Bondt-van den Essen from Thompson's dimension-24 form; **does not cite Meng-Yang**.

Notable correction documented there: "Thompson's cubic-homogeneous form in dimension
24 (verified independently; nilpotency index corrected from 17 to 18)" — i.e.,
Thompson's sbseminar claim (JN)^17 = 0 was corrected to index 18. This is the only
actual dispute/correction found anywhere in the cascade literature; it does not touch
the Meng-Yang construction.
